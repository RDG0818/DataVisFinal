# Extraction contract
Use official university CDS PDFs/XLSX/HTML only as published observations. Target Fall 2019-2025 (edition beginning year = cohort_year only when the question explicitly refers to that fall). No filled values from IPEDS or secondary compilations.
Each agent writes shards/<group>/observations.csv using columns:
school,unitid,cohort_year,cds_edition,section,metric,population,gender,residency,value,unit,source_url,page,extraction_method,verification_status,notes
population defaults first_time_first_year; gender defaults total; residency defaults all. value numeric string; missing omitted (never zero). metric names: applicants, admitted, enrolled, waitlist_offered, waitlist_accepted, waitlist_admitted, sat_submit_pct, act_submit_pct, sat_composite_p25/p50/p75, sat_ebrw_p25/p50/p75, sat_math_p25/p50/p75, act_composite_p25/p50/p75, hs_rank_top10_pct, hs_rank_top25_pct, hs_rank_top50_pct, hs_rank_reported_pct, hs_gpa_mean, undergraduate_enrollment, aid_need_determined_count, aid_need_based_received_count, aid_need_fully_met_count, aid_need_met_pct, aid_need_based_grant_mean_usd. GPA bins optional names hs_gpa_4plus_pct etc. For aid population use full_time_first_year or full_time_undergraduate and aid_year note if prior year. Percentage values 0-100. Counts integers.
Keep raw files under raw/<group>, extracted text in sources/<group>. Download with timeouts and one request per host at once, small bounded concurrency only. Save source manifest shards/<group>/sources.csv with school,unitid,cohort_year,cds_edition,source_url,local_path,sha256,retrieved_at,format,status,notes. Metadata status may contain blocked/unavailable sources.
School-year requires C1 total applicants/admitted/enrolled to be included. Deriving explicitly as sum of reported men+women+other is allowed only with method=derived_sum_of_reported_categories and notes of operands. Do not conflate FT and PT. Page is 1-based physical PDF page (sheet name/HTML anchor for non-PDF). Capture actual table context, not text-only numbers without headers. C1 extraction may be auto plus manual table review; use verification_status=source_table_reviewed when you actually inspect table context, otherwise parsed_unreviewed. Do not upload anything or modify shared integration files. Write extraction script and shard README documenting limitations and uncovered fields. Priority: >=10 schools with complete C1, >1 year where possible, then requested C9/B1/C2/GPA/H. Root handles IPEDS matching, final QA/package/upload.
